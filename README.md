# agnubin

크롬·엣지(Chromium)용 브라우저 데이터 정리 확장프로그램입니다.

## 설치

1. 브라우저에서 `chrome://extensions`를 엽니다. (엣지는 `edge://extensions`)
2. **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 이 폴더를 선택합니다.

## 사용

- 확장프로그램 팝업에서 전체 선택 데이터 또는 현재 사이트 데이터를 정리합니다.
- 설정 페이지에서 지울 데이터 유형과 기간을 고릅니다.
- “브라우저를 닫을 때 정리하기”를 켜면 마지막 브라우저 창을 닫을 때 선택한 데이터를 정리합니다. 탭과 세션 복원 데이터는 건드리지 않습니다. 종료 과정에서 Chrome이 작업을 중단하면, 다음 시작 시 자동으로 한 번 더 정리합니다.
- “정해 둔 시간마다 정리하기”를 켜고 1분~10,080분 사이의 주기를 입력하면, 브라우저가 열려 있는 동안 선택한 데이터를 반복 정리합니다.
- 단축키는 설정 페이지의 “단축키 설정 열기”에서 브라우저가 제공하는 화면으로 지정합니다.

현재 사이트 정리는 사이트별로 지원되는 데이터(쿠키, 캐시, 사이트 저장공간, 방문 기록 등)만 처리합니다. 양식 자동완성, 다운로드 기록처럼 사이트별 구분이 불가능한 항목은 전체 정리에서만 지울 수 있습니다.

Chrome 144 이후에는 확장프로그램이 저장된 비밀번호 삭제를 할 수 없습니다. AppCache, Web SQL, Flash 플러그인 데이터도 최신 Chromium 브라우저에서 종료되어 설정에 비활성 항목으로 표시됩니다.
